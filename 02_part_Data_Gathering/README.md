# Part 2: Data Gathering

Goal: Explain where data comes from and introduce the workshop's dataset.

The Golden Rule of ML (5 mins): Emphasize that you need a good amount of data of the right type. Explain "Garbage In, Garbage Out." A model is only as good as the data it learns from. Documenting origins and being aware of biases (e.g., are we only looking at luxury listings?) is crucial.

Data Sources (5 mins): * Briefly discuss how we get data: Web scraping (extracting from HTML), APIs, and open datasets (like Kaggle or Inside Airbnb).

Tip for the course: Don't do live scraping; it takes too long. Tell them, "For today, I have pre-retrieved a dataset of Airbnb listings."

Exploring our Airbnb Data (5 mins): Load the dataset. Look at the raw rows and columns to show how messy real-world data can be before we touch it.
